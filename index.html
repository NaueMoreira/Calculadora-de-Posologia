💊 Dispensação de Medicação 💊

Esse sistema web serve para calcular a quantidade de medicação que o paciente necessita para o tratamento. O sistema consiste em dispensação de comprimidos e líquidos, sendo que os líquidos têm maior disponibilidade de fórmulas farmacêuticas (gotas, xaropes, insulina, etc...)
