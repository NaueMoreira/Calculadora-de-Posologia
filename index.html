💊Dispensação de Medicação!💊

Esse sistema web serve para calcular a quantidade de medicação que o paciente necessita para o tratamento, o sistema consiste em sistema de dispensação de comprimidos e líquidos, sendo que os líquidos têm maior disponibilidade de fórmulas farmacêticas(gotas, xaropes ,insulina, etc...)
